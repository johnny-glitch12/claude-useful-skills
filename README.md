# Claude Useful Skills

A collection of ready-to-use Skills for Claude (claude.ai and Claude Code).

These are not MCP servers. They are Claude Skills — folders with a `SKILL.md` that teach Claude specific workflows.

## How to use

### On claude.ai
1. Zip the skill folder (the folder itself must be the root of the zip)
2. Go to **Customize > Skills**
3. Click **+** → **Upload a skill**
4. Upload the zip

### On Claude Code
You can copy the skill folders into your project's `.claude/skills/` directory, or use community skill installers.

## Included skills

| Skill | What it does |
|-------|--------------|
| `code-reviewer` | Reviews code for bugs, style, and improvements |
| `readme-writer` | Writes clear, professional README.md files |
| `commit-message` | Writes good conventional commit messages |
| `debugger` | Systematic debugging steps for errors |
| `docs-writer` | Turns code or notes into clean documentation |

## Why these skills?

They solve common, repeatable tasks that people ask Claude to do over and over. Once uploaded, Claude can use them automatically when the task matches.
