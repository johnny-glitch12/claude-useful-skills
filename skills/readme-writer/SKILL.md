# README Writer

When asked to write or improve a README, produce a complete, ready-to-use README.md.

## Structure to follow

1. **Title** — Project name + one-line description
2. **What it does** — Short explanation of the purpose
3. **Features** — Bullet list of key features
4. **Installation** — Clear steps (clone, install deps, run)
5. **Usage** — Real examples with commands or code
6. **Configuration** (if needed)
7. **Contributing** (optional short section)
8. **License**

## Rules

- Keep language simple and direct
- Use code blocks for commands
- Make the installation and usage sections copy-paste ready
- Do not invent features that don't exist
- Prefer short sections over long walls of text
